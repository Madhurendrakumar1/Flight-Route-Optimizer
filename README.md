# Flight Route Optimizer

## About the Project
Flight Route Optimizer is a C++ application that manages cities and flight routes using graph data structures.

## Features
- Add and manage cities
- Add and remove flight routes
- Prevent duplicate routes
- Explore connected cities using BFS
- Find shortest-distance routes using Dijkstra's algorithm
- Store route distance and cost information

## Technologies Used
- C++
- Graphs and adjacency lists
- C++ Standard Template Library (STL)
- BFS (Breadth-First Search)
- Dijkstra's Algorithm

## How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Compile the C++ source file using a C++ compiler.
4. Run the generated executable.

## Purpose
This project was developed for academic learning and to practise graph algorithms and problem-solving in C++.
